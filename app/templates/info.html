LOCAL PLAY & CONNECTIONS

Information

Everything needed to run Emporos locally and connect your preferred desktop AI client.

PLAY WITHOUT AI

Standalone game

Run Start Emporos.bat, then use a Human Referee campaign. Emporos handles rules, records, maps, characters, trade, travel, and combat without contacting any AI service.

PLAY WITH AI

Desktop MCP client

Your ChatGPT, Claude, SillyTavern, or other MCP-capable desktop client supplies the model. Emporos supplies private campaign state and deterministic game tools. Your client account owns model choice and cost.

MCP CONNECTION

Connect your desktop client

LOCAL STDIO
  1. Make sure Emporos has a working .env database configuration.
  2. Open your desktop client's MCP server settings.
  3. Add a local standard-input/output server using the configuration below.
  4. Restart or reconnect the desktop client, then ask it to call emporos_status.

Different clients place MCP settings in different menus, but the command and arguments are the same.

{
  "mcpServers": {
    "emporos": {
      "command": "{{ powershell_path|replace('\\','\\\\') }}",
      "args": [
        "-NoLogo",
        "-NoProfile",
        "-ExecutionPolicy",
        "Bypass",
        "-File",
        "{{ mcp_script|replace('\\','\\\\') }}"
      ]
    }
  }
}

No AI API key is entered into Emporos. The MCP connection is local, and the desktop client remains responsible for its own model subscription and memory.

AVAILABLE TO THE CLIENT

What the connection can do

Read campaign truth
Campaigns, characters, ships, systems, clocks, sources, and recent narration.

Run the referee
Receive pending actions and return narration while mechanics stay inside audited commands.

Use the engine
Invoke allowlisted deterministic gameplay tools and receive permanent receipts.

Keep the log
Archive ordered desktop conversations as readable Captain's Logs in the Journal.
